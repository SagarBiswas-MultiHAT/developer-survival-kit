## 🧠 Methodology

All research notes in this repository follow these principles:

- **Primary sources only** - every claim cites a named study, dataset, or official platform documentation
- **BST-first lens** - generic global data is always reconciled against Bangladesh Standard Time (UTC+6) audience patterns
- **Quantitative basis** - recommendations are derived from statistically significant samples, not anecdote
- **Living documents** - notes are versioned and updated as new data becomes available

## 🚀 Featured Research

### [📊 POSTING-TIME STRATEGY.md](./notes/POSTING-TIME%20STRATEGY.md)
**Best times to post technical content on LinkedIn & Facebook (BST, 2026)**

Data from:
- Buffer's July 2026 analysis of **4.8 million LinkedIn posts**
- Sprout Social's March 2026 analysis of **~2 billion engagements across 307,000 profiles**
- Facebook's official Group Insights documentation

**TL;DR:**
- 🟢 **LinkedIn best slot:** Wednesday, 4:00 PM BST
- 🔵 **Facebook group best slot:** Wednesday, 7:30 PM BST
- Timing is the *last* optimization layer - content relevance, hook quality, and engagement velocity matter more
